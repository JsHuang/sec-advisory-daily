漏洞描述：NocoBase 的站内消息插件中，GET /api/myInAppChannels:list 接口的 filter 参数中 latestMsgReceiveTimestamp 字段的 $lt 值被直接拼接到 Sequelize.literal() 模板字符串中，无任何转义、类型转换或参数绑定。攻击者仅需注册并登录（默认开启注册），即可通过精心构造的 filter 参数注入 SQL，结合 PostgreSQL 超级用户权限（Docker 默认配置），可通过 COPY...TO PROGRAM 执行系统命令，实现 RCE。

触发条件：发送带有 filter[latestMsgReceiveTimestamp][$lt]=恶意SQL 的 GET 请求到 /api/myInAppChannels:list

潜在危害：SQL注入 → 数据窃取 → 通过 PostgreSQL COPY TO PROGRAM 实现远程代码执行（RCE），完全控制数据库容器

可利用性：有完整 PoC（包含 curl 命令和完整利用链），攻击门槛极低
