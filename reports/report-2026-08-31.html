🔴 vm2: 使用危险的 Host Proto Mutators 实现沙箱逃逸
GHSA-cfcw-xp6x-25gj | CVE: CVE-2026-47698
优先级: 高
Critical (CVSS 9.8) ⭐ 4,093 🔴 PoC Available

漏洞描述：VM2 存在沙箱逃逸漏洞。此前针对 GHSA-v6mx-mf47-r5wg 的修复不完整，攻击者可通过将 indirectcall.call(dangerousmutator, ...) 替换为 indirectcall.call(indirectcall, dangerousmutator, ...) 来绕过修复，因为间接调用不被视为危险操作。攻击者可在 VM2 沙箱内执行任意代码并逃逸到宿主系统。

影响产品：vm2 (npm) ⭐ 4,093

影响版本：<= 3.11.5

修复版本：3.11.6

攻击面：任何使用 VM2 运行不可信 JavaScript 代码的应用场景，包括在线代码执行平台、插件系统、CI/CD 管道中的脚本执行等。

触发条件：攻击者能够在 VM2 沙箱内执行任意 JavaScript 代码即可触发。无需任何用户交互或额外权限。

潜在危害：远程代码执行（RCE）— 攻击者可完全控制宿主系统，执行任意系统命令，窃取敏感数据，横向移动至内网其他系统。CVSS 评分 9.8（网络/低复杂度/无需权限/无需交互）。

可利用性：有完整 PoC 代码，可直接复制执行。利用链清晰：通过 __lookupGetter__/__lookupSetter__ 获取 __proto__ 的 getter/setter，利用 WebAssembly.compileStreaming 异常触发原型链污染，最终通过 constructor.constructor 获取 process 对象执行系统命令。

CWE分类：CWE-913 - 对动态管理代码资源的不当控制

PoC 代码：

const vm = new VM();

  • 如果无法立即升级，考虑迁移到 nicedayzhu/vm2（社区维护分支）或使用 isolated-vm 替代方案
