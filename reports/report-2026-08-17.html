优先级: 中

漏洞描述：mcp-ssh-tool 是一个基于 MCP 协议的 SSH 远程管理工具。该漏洞涉及两个安全问题：(1) 文件传输路径授权策略存在路径遍历绕过（CWE-22），攻击者可通过精心构造的路径绕过 deny-prefix 策略检查，访问受限目录下的文件；(2) HTTP Bearer Token 比较未使用常量时间算法（CWE-208），存在时序侧信道攻击风险，可能导致 Token 泄露。

影响产品：mcp-ssh-tool（npm 生态，仓库已删除，Star 数不可考）

影响版本：≤ 2.1.0

攻击面：MCP 客户端通过 SSH 进行文件传输时的路径授权检查；HTTP 传输层的 Bearer Token 认证

触发条件：(1) 路径遍历：MCP 客户端发起文件传输请求，使用路径分隔符边界或规范化的变体绕过 deny-prefix 检查；(2) 时序攻击：攻击者可对 HTTP 端点发送大量认证请求，通过响应时间差异推断 Bearer Token

潜在危害：路径遍历可导致敏感文件读取/写入；时序侧信道可导致认证令牌泄露
