🔴 紧急 PostCSS: Arbitrary file read and information disclosure via attacker-controlled sourceMappingURL in CSS comments
GHSA-6g55-p6wh-862q | CVE: CVE-2026-45623
优先级: 9/11
High ⭐ 28,972 🔴 PoC Available 📖 详细分析

漏洞描述：PostCSS的PreviousMap模块解析CSS中的sourceMappingURL注释时，直接将PATH路径与本地文件系统拼接，无任何协议白名单或路径遍历检查。攻击者可通过构造恶意CSS，读取Node进程可读的任意文件，并通过JSON.parse错误信息泄露前~10字节内容。

影响产品：postcss/postcss ⭐28,972

影响版本：npm:postcss (<= 8.5.11)

攻击面：任何将不可信CSS传入PostCSS的管道（CMS主题、用户上传样式、浏览器扩展、第三方包构建管道等）

触发条件：默认配置即可触发，无需from、map或插件选项

潜在危害：任意文件读取和信息泄露；文件存在性探测；大文件DoS

可利用性：有完整PoC

修复建议：升级至 postcss >= 8.5.12

潜在危害：认证绕过 - 所有访客被视为已认证，可访问受保护资源
