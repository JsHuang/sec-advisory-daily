🔴 n8n Expression 沙箱逃逸：箭头函数体绕过实现命令执行
GHSA-gv7g-jm28-cr3m
优先级: 极高
High ⭐ 198,265 stars 🔴 有利用原理（fix commit 含完整触发路径） 📖 详细分析

漏洞描述：n8n 表达式求值器存在沙箱逃逸漏洞。经过身份验证的用户（拥有创建或修改 workflow 权限）可以通过构造使用箭头函数（arrow function）的表达式，绕过表达式沙箱，在运行 n8n 的主机上触发非预期的系统命令执行。

影响产品：n8n-io/n8n ⭐ 198,265 stars

影响版本：n8n < 2.31.5 和 n8n >= 2.32.0 < 2.32.1

攻击面：任何有权访问 n8n 实例并能创建/编辑 workflow 的用户均可触发；多租户/嵌入式场景下风险尤为突出。

触发条件：在 workflow 表达式中使用形如 () => process 的简洁箭头函数体（concise arrow body），该标识符会直接从数据上下文中解析，从而泄漏宿主全局对象引用，进一步链式调用即可执行任意命令。

潜在危害：远程代码执行（RCE）——攻击者可在 n8n 服务器进程权限下执行任意系统命令，可能导致数据泄露、权限提升、横向移动。

可利用性：高。修复 commit（f69dfc6）清晰展示了漏洞触发路径：在 VariablePolyfill.ts 中新增了 ArrowFunctionExpression 类型的处理分支，阻止简洁箭头函数体作为裸标识符直接解析；同时在 isolated-vm-bridge.ts 中加固了数组索引访问，防止通过非索引键（如 constructor、__lookupGetter__）泄漏宿主函数引用。结合这两处变更，攻击者可以逆向构造出完整的利用链。

修复建议：立即升级至 n8n 2.31.5 或 2.32.1+；临时缓解：将 n8n 实例访问权限限制为仅可信用户，限制 workflow 创建和编辑权限。

🟠 goodoneuz/pay-uz：未认证 PHP 文件覆写导致远程代码执行
GHSA-m5wg-cjgh-223j | CVE: CVE-2026-31843
优先级: 高
Critical (CVSS 9.8) ⭐ 86 stars 🔴 有完整利用路径

漏洞描述：goodoneuz/pay-uz Laravel 支付包（≤ 2.2.24）的 /payment/api/editable/update 端点存在严重漏洞。该端点通过 Route::any() 注册，未配置身份验证中间件，允许未认证的远程攻击者直接访问。用户可控输入通过 file_put_contents() 直接写入可执行 PHP 文件，这些文件在正常支付处理流程中通过 require() 被执行，最终实现远程代码执行。

影响产品：goodoneuz/pay-uz ⭐ 86 stars（Composer 包）

影响版本：≤ 2.2.24（修复版本：3.0.0）

攻击面：任何能访问目标服务器的网络攻击者均可利用，无需任何认证。适用于使用乌兹别克斯坦支付集成的 Laravel 应用。

触发条件：直接向 /payment/api/editable/update 发送请求，携带恶意 PHP 代码作为参数，即可覆写现有支付钩子文件。

潜在危害：完全的远程代码执行（CVSS 9.8），攻击者可接管应用服务器、窃取支付数据、植入后门。

可利用性：极高。公告明确指出：端点无认证、file_put_contents() 直接写入、require() 触发执行，三步完整利用链清晰可见；攻击成本极低。

修复建议：升级至 pay-uz 3.0.0+；若无法立即升级，应通过 Nginx/WAF 规则拦截该端点的未授权访问请求。
