🔴 Budibase: 任意文件读取 (PWA-zip 符号链接上传)
GHSA-w7mq-r738-x278 | CVE: CVE-2026-54352
优先级: 紧急
Critical ⭐ 28,051 🔴 PoC Available 📖 详细分析

漏洞描述：Budibase 的 PWA zip 上传功能存在符号链接漏洞。攻击者（workspace builder）可上传包含指向任意文件的符号链接的 zip，绕过路径检查，读取服务器上任意文件（包括 /data/.env 中的 JWT_SECRET、数据库密码等敏感凭据）。

影响产品：Budibase ⭐28,051

影响版本：< 3.39.9

攻击面：已认证的 workspace builder 通过 POST /api/pwa/process-zip 上传恶意 zip

触发条件：上传包含符号链接的 zip 文件，符号链接指向 /data/.env 或其他敏感文件

潜在危害：读取容器内任意 root 可读文件，包括密钥、密码、数据库凭据等

可利用性：有完整PoC

修复建议：升级至 Budibase >= 3.39.9

🔴 Mise: .tool-versions 文件中的 Tera 模板任意代码执行 (Trust Bypass)
GHSA-fjj5-v948-whjj | CVE: CVE-2026-33646
优先级: 紧急
Critical ⭐ 29,895 📖 详细分析

漏洞描述：Mise 在解析 .tool-versions 文件时通过 Tera 模板引擎处理，且注册了 exec() 函数可执行任意命令。与 .mise.toml 不同，.tool-versions 文件在非 paranoid 模式下不受信任检查。攻击者可在 git 仓库中放置恶意 .tool-versions 文件，当用户 cd 进入目录时自动执行任意命令。

影响产品：Mise ⭐29,895

影响版本：< 2026.3.10

攻击面：用户 cd 进入包含恶意 .tool-versions 的 git 仓库目录

触发条件：victim 克隆恶意仓库并激活 mise shell hook

潜在危害：任意代码执行，可导致供应链攻击

可利用性：有详细原理

修复建议：升级至 Mise >= 2026.3.10，或使用 paranoid 模式
