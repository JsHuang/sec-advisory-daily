🔴 紧急 MCP Python SDK: Experimental task handlers allow any client to access and cancel other clients' tasks
GHSA-hvrp-rf83-w775 | CVE: CVE-2026-52870
优先级: 10
HIGH⭐ 23,633🔴 PoC Available📖 详细分析

漏洞描述：MCP Python SDK的实验性任务处理功能（server.experimental.enable_tasks()）未对任务创建者进行会话验证。在多客户端连接的服务器上，任意客户端可以观察、读取、取消其他客户端的任务。

影响产品：MCP Python SDK (Model Context Protocol) ⭐23,633

影响版本：mcp >= 1.23.0, <= 1.27.1

攻击面：任何连接到MCP服务器的客户端（包括恶意客户端），需要服务器启用了实验性tasks功能

触发条件：服务器调用 server.experimental.enable_tasks() 且同时有多个客户端连接

潜在危害：任务结果泄露、elicitation请求被窃取、任务被恶意取消，可导致跨客户端数据泄露和服务中断

可利用性：有完整PoC - 攻击者只需连接到MCP服务器即可枚举所有任务（tasks/list），无需预先知道任务ID

修复建议：升级到 mcp >= 1.27.2，该版本在任务ID中嵌入了会话标识并限制了跨会话访问
