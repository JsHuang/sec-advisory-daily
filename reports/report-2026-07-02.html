🔴 repomix 远程代码执行漏洞（命令注入）
GHSA-9mm9-rqhj-j5mx | CVE: CVE-2026-49987
优先级: 极高
High ⭐ 26.8k 🔴 PoC Available 📖 详细分析

漏洞描述：repomix 的 --remote-branch CLI 参数存在命令注入漏洞。用户输入直接传递给 git fetch 和 git checkout 子进程，未经过任何消毒、-- 分隔符或验证。攻击者可注入任意 git 命令行选项，通过 --upload-pack 参数指定恶意二进制文件实现任意命令执行。

影响产品：repomix ⭐26,755

影响版本：< 1.14.1（已修复）

攻击面：CLI 用户输入 → git 子进程参数注入

触发条件：执行 repomix --remote <url> --remote-branch '--upload-pack=/tmp/malicious-pack'

潜在危害：完全控制系统权限；CI/CD 环境泄露密钥；供应链攻击

可利用性：有完整PoC代码和复现步骤，包含端到端攻击流程

修复建议：立即升级至 v1.14.1+；在 git 命令中使用 -- 分隔符；对分支参数应用危险参数黑名单

🔴 SurrealDB HTTP /rpc 会话劫持漏洞
GHSA-5qfp-32cf-69jh | CVE: 无
优先级: 极高
High ⭐ 32.6k 📖 详细分析

漏洞描述：SurrealDB HTTP /rpc 端点的 sessions 方法无需认证即可返回所有已附加会话的 UUID，且 /rpc 处理器接受任意 session 字段而无所有权验证。匿名攻击者可枚举 UUID 并冒充任何已认证会话。

影响产品：SurrealDB ⭐32,581

影响版本：< 3.1.0（已修复）

攻击面：HTTP /rpc 端点，暴露于网络的 SurrealDB 实例

触发条件：向 /rpc 发送 sessions 请求获取 UUID，随后使用获取的 UUID 发送请求

潜在危害：读取/写入/删除任意数据；权限提升至 root 级别；完全控制数据库

可利用性：有详细漏洞原理说明，攻击路径清晰

修复建议：升级至 v3.1.0+；避免使用 SDK 的 attach 功能；限制 /rpc 端点网络访问

🔴 Centrifugo JWT 认证绕过（跨租户身份伪造）
GHSA-g6vg-wj8f-48cj | CVE: CVE-2026-49998
优先级: 极高
High ⭐ 10.5k 🔴 PoC Available 📖 详细分析

漏洞描述：Centrifugo 的动态 JWKS 端点功能仅使用 JWT header 的 kid 值作为缓存键，而非 JWKS 端点、issuer、audience 或其他信任域命名空间。当多个 issuer 的 JWKS 文档使用相同 kid 值时，攻击者可使用租户 A 的有效令牌认证为租户 B，实现跨租户身份伪造。

影响产品：Centrifugo ⭐10,463

影响版本：v6 <= 6.8.0, v5 <= 5.4.9, v4 <= 4.1.5, v3 <= 3.2.3（仅 v6.8.1 已修复）

攻击面：多租户实时通信系统，使用动态 JWKS 配置

触发条件：获取租户 A 的有效令牌，当两个租户 JWKS 使用相同 kid 时伪造租户 B 的令牌

潜在危害：跨租户数据泄露；未授权访问其他租户的 WebSocket 连接和订阅

可利用性：有完整 PoC 单元测试代码，详细源码分析

修复建议：升级至 v6.8.1+；确保不同租户 JWKS 使用不同 kid 值；限制 JWKS 端点访问
